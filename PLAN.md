# Proyecto de Control de Gastos Personales

## Arquitectura del Proyecto
- **Backend**: Python con el micro-framework Flask.
- **Base de Datos**: SQLite, usando una tabla `expenses` para almacenar información de los gastos.
- **Frontend**: Construido con HTML, CSS, y JavaScript "vanilla".

## Características del MVP (Minimum Viable Product)
- Crear un nuevo gasto especificando descripción, monto, categoría y fecha.
- Las categorías de los gastos se seleccionan de una lista estándar: Comida, Transporte, Entretenimiento, Servicios, y Otros.
- Listar los gastos existentes, ordenados del más reciente al más antiguo.
- Eliminar un gasto de la lista.
