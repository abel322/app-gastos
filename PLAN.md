# Plan del Proyecto: Control de Gastos Personales

## Arquitectura del Proyecto
- **Backend:** Python Flask
- **Base de Datos:** SQLite
- **Frontend:** HTML, CSS, JavaScript Vanilla

## Características del MVP (Producto Mínimo Viable)
- **Agregar gastos:** Permite a los usuarios registrar un nuevo gasto con descripción, monto, categoría y fecha.
- **Ver gastos:** Muestra una lista de todos los gastos registrados, ordenados por fecha.
- **Eliminar gastos:** Permite a los usuarios eliminar gastos existentes.
