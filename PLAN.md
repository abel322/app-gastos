# Plan y Arquitectura del Proyecto

## Arquitectura
- **Backend:** Flask (Python)
- **Base de Datos:** SQLite (archivo `expenses.db` con una tabla `expenses` que incluye id, description, amount, category, date).
- **Frontend:** HTML, CSS, Javascript (Vanilla JS), comunicándose con el backend a través de una API REST.

## Funcionalidades Actuales
- Listar todos los gastos.
- Agregar nuevos gastos (descripción, monto, categoría, fecha).
- Eliminar gastos existentes.
