# Plan del Proyecto: App de Gastos Personales

## Arquitectura del Proyecto
- **Backend**: Python con Flask.
- **Base de Datos**: SQLite (archivo `expenses.db`).
- **Frontend**: HTML, CSS, JavaScript (Vanilla).

## Características de la Aplicación
- **Agregar gastos**: Permite ingresar la descripción, el monto, la categoría y la fecha de un gasto.
- **Ver gastos**: Muestra una lista de todos los gastos registrados.
- **Eliminar gastos**: Permite borrar un gasto de la lista.

## Categorías Estándar
Los gastos se clasifican en las siguientes categorías estándar:
- Comida
- Transporte
- Entretenimiento
- Servicios
- Otros
