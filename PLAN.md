# Control de Gastos Personales

## Arquitectura del Proyecto
- Backend: Python Flask
- Base de datos: SQLite (`expenses.db` con una tabla `expenses` que contiene `id`, `description`, `amount`, `category`, y `date`)
- Frontend: HTML, CSS, JavaScript puro (Vanilla JS)

## Funcionalidades del MVP
- Agregar un gasto (Descripción, Monto, Categoría, Fecha)
- Ver una lista de todos los gastos ordenados por fecha
- Eliminar un gasto
- Categorías estándar: Comida, Transporte, Entretenimiento, Servicios, Otros
- La interfaz de usuario de la aplicación está localizada en español.
