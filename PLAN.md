# Plan del Proyecto: Control de Gastos Personales

## Arquitectura
- **Backend**: Python con Flask.
- **Base de Datos**: SQLite (`expenses.db`).
- **Frontend**: HTML, CSS, JavaScript vainilla (UI localizada en español).

## Funcionalidades
- Agregar gastos (descripción, monto, categoría, fecha).
- Listar todos los gastos ordenados por fecha.
- Eliminar gastos existentes.
- Categorías estándar: Comida, Transporte, Entretenimiento, Servicios, y Otros.
