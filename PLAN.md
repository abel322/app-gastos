# Plan del Proyecto: Control de Gastos Personales

## Arquitectura del Proyecto
- **Backend:** Desarrollado utilizando Python y el framework Flask.
- **Base de Datos:** SQLite, almacenada en el archivo `expenses.db`.
- **Frontend:** HTML, CSS y Vanilla JavaScript.

## Características
- **Registrar Gastos:** Permite a los usuarios agregar nuevos gastos especificando descripción, monto, categoría y fecha.
- **Visualizar Gastos:** Muestra una lista de todos los gastos registrados.
- **Eliminar Gastos:** Permite borrar gastos existentes.
