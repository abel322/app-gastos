# Control de Gastos Personales

## Arquitectura del Proyecto
Este proyecto utiliza la siguiente pila tecnológica:
- **Backend:** Python con Flask
- **Base de Datos:** SQLite
- **Frontend:** HTML, CSS y Vanilla JavaScript

## Funcionalidades MVP (Producto Mínimo Viable)
Las funcionalidades principales de la aplicación incluyen:
1. **Agregar gastos:** Permite a los usuarios registrar un nuevo gasto con su descripción, monto, categoría y fecha.
2. **Ver gastos:** Muestra una lista de todos los gastos registrados.
3. **Eliminar gastos:** Permite a los usuarios eliminar un gasto existente de la lista.

## Categorías de Gastos
Las categorías estándar de gastos son:
- Comida
- Transporte
- Entretenimiento
- Servicios
- Otros
