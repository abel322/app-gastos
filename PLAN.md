# Plan del Proyecto: Control de Gastos Personales

## Arquitectura
- **Backend:** Python con Flask.
- **Base de Datos:** SQLite (`expenses.db`).
- **Frontend:** HTML, CSS y JavaScript vainilla (Vanilla JS).
- **Idioma de la interfaz:** Español.

## Funcionalidades del MVP (Producto Mínimo Viable)
- **Agregar Gasto:** Los usuarios pueden agregar un gasto especificando descripción, monto, categoría y fecha.
- **Listar Gastos:** Los usuarios pueden ver una lista de todos los gastos agregados.
- **Eliminar Gastos:** Los usuarios pueden eliminar un gasto específico de la lista.
- **Categorías Estándar:** Las categorías disponibles son: Comida, Transporte, Entretenimiento, Servicios y Otros.
