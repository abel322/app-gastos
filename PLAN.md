# Plan de Arquitectura y Características
## Arquitectura
* Backend: Python con Flask
* Base de Datos: SQLite
* Frontend: HTML, CSS, JavaScript (Vanilla)

## Características
* Añadir gastos (Descripción, Monto, Categoría, Fecha)
* Ver lista de gastos
* Eliminar gastos
* Categorías de gastos estándar:
  * Comida
  * Transporte
  * Entretenimiento
  * Servicios
  * Otros
